# Rootes v. Thomas

## Majority (Whitfield, C. J.,)

Whitfield, C. J.,
delivered the opinion of the court.
It was manifest error not to allow the amendment of the jurat, if it should be conceded that it needed amendment.
The decree pro confesso is set aside; the cause is reversed and remanded, to be proceeded with in accordance with this opinion.
